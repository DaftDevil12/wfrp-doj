Drop the gavel sound file here as: gavel.mp3

Recommended source (the one chosen for this resource):
  https://www.myinstants.com/en/instant/gavel-1-78972/

How to install:
  1. Open the link above in a browser
  2. Click the "Download MP3" button on the page
  3. Save the file into this folder, renamed to: gavel.mp3
  4. Restart the resource (restart wfrp-doj)

If gavel.mp3 is missing, the resource automatically falls back to a
synthesized gavel sound generated in-browser. The custom file just
sounds better.

If you want to use .ogg or .wav instead, edit ui/app.js and change
the GAVEL_URL constant near the top of the file.
